# 04: 公平二分法闭环控制（核心弹道）

**What to build:** 核心算法落地：新增「IEEE 33 + 高渗透光伏过电压」预设，其上运行控制闭环——先按论文计算公平责任权重 ω_i = (R_i)^α·(C_i)^β / Σ…（R_i = |S_vp,i|·P_cur,i 归一化，S_vp,i 为对当前越限最严重节点的有功灵敏度、由潮流摄动计算；C_i 历史补偿因子；H_i 累计弃光率、24h 模式跨断面按小时顺序累积），再在 C ∈ [0, 总可用出力] 上二分搜索总削减量，max(V) 落入收敛带 [Vmax−δ, Vmax] 即停；削减按 C*×ω_i 分配，超出可用出力者全停并标记「已饱和」；达迭代上限取保守可行侧并标注「未收敛」。快照与 24h 模式均可收敛，每轮二分状态与最终分配全程可查；随结果输出 Jain 公平指标（论文式 24–26）。控制算法集中在单文件（NFR-4），α/β/γ、δ、迭代上限经 §5 参数可配。**论文已核对（spec §9）：ω_i 每断面开始计算一次、二分中固定（Q-1 确认）；H 每次运行从 0 累积、不跨运行持久化（Q-2 确认）。**
