# 01: 项目骨架与网络模型（schema 全量 + 校验 + validate CLI）

**What to build:** 仓库可运行的最小闭环：安装依赖后 `python -m pvvr validate project.json` 能加载并校验项目 JSON，违规给中文行级/字段级报错；内置 IEEE 33（三相均分复制）与小型纯单相两个预设，可加载、可另存；项目文件带 `schema_version`，保存→加载→再保存内容等价；含环路的项目被拒绝并列出参与环路的节点/线路清单；设置（MATLAB 路径占位、§5 参数默认值等）持久化读写。**全量项目 schema 在本票一次定齐**：节点/线路/光伏/网络参数/统一曲线/通信图/算法参数——后续票只加行为、不改 schema 结构。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] `pvvr validate` 对两个内置预设通过；对缺字段、编号重复、线路端点不存在、相别非法、容量为负、曲线非 24 点给出中文定位报错
- [ ] 含环路项目被拒绝，报错列出参与环路的节点与线路清单（验收 6 之环路部分）
- [ ] JSON 保存→加载→再保存内容等价（验收 6）
- [ ] IEEE 33 预设数据与 Baran & Wu 原始数据一致（线路与负荷三相均分复制）
- [ ] schema 含统一曲线、通信图、§5 全部参数字段；设置持久化读写生效
- [ ] Python 3.8 与 3.12 下依赖可安装、validate 可运行；requirements 固定版本（NFR-2/7）
