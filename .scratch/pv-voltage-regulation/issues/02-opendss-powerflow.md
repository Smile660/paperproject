# 02: OpenDSS 单断面潮流（IEEE 33 基态 tracer）

**What to build:** 用户在 CLI 运行 `python -m pvvr run project.json --mode snapshot`，平台把网络模型翻译为 OpenDSS 模型（opendssdirect 内置引擎，无需独立安装），求解三相不平衡潮流，输出全部节点分相电压（pu）与线路负载率到控制台和 CSV。潮流求解设置（Newton、收敛容差、最大迭代）按 §5 统一配置，为双引擎一致性打底。IEEE 33 基态复现文献最低电压，成为项目的第一条回归测试。

**Blocked by:** 01: 项目骨架与网络模型

**Status:** ready-for-agent

- [x] IEEE 33 基态最低电压 ≈0.913 pu（节点 18），与文献偏差 <0.5%（ET-1、验收 1）——实测 0.9132 pu，偏差 0.01%
- [x] 输出全部节点分相电压（pu）与线路负载率 CSV
- [x] 三相混接模型可求解：单相负荷/光伏正确指定 A/B/C 相（混接最小例测试通过）
- [x] 潮流不收敛时给中文诊断报错（FR-9），不崩溃退出
- [x] 单断面潮流 IEEE 33 规模毫秒级完成（NFR-1）——实测 ~30 ms

## Comments

- 2026-10-01 完成。引擎适配踩坑记录（均已写入代码注释/测试）：① 多行脚本须经临时文件 `compile`（Text.Command 直发矩阵语法会解析中断）；② 本引擎构建 `Set Frequency=50` 会把解归零——模型阻抗为绝对 Ω、潮流解与频率无关，引擎按默认频率求解等价，频率字段留给 MATLAB 引擎；③ Vsource basekv 一律按线电压处理（含单相源）；④ 单相负荷必须显式 `phases=1`（默认 3 相会自动扩展节点导致三相混乱）；⑤ pu 不用 AllBusMagPu（单节点母线基准差 √3 倍），统一按 相电压/(Vll/√3) 自行换算；⑥ Vsource 零阻抗被拒绝，用 1e-6 Ω 近似理想源。
