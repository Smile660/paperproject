# 05: 对比基线（无控制 + 集中式 k 二分 + 一键对比）

**What to build:** 同一项目上一键运行三种方式并排对照：①无控制基线（光伏按可用出力满发不调节）；②集中式基线（不经一致性、直接二分搜索全局削减系数 k，各光伏等比例削减：出力 = k × 可用出力）；③公平二分法。CLI 产出对比图（电压轨迹叠加、削减分配柱状对比）与指标表：总削减电量（kWh）、峰值时刻削减量、最大/最小电压、外层迭代数、总耗时。对比结果与单次运行同目录落盘、可互相参照。

**Blocked by:** 04: 公平二分法闭环控制

**Status:** ready-for-agent

- [ ] 三种方式对同一断面/同一典型日均运行成功，结果同目录可对照
- [ ] 集中式基线收敛后同样满足 max(V) ≤ Vmax（等比例分配）
- [ ] 无控制基线全天满发不调节，越限如实暴露
- [ ] 对比图与指标表落盘（PNG + CSV），中文无乱码
- [ ] 指标表数值与各运行明细自洽（削减电量可由轨迹复算）
