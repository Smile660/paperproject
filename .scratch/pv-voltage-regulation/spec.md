# 分布式光伏电压调节仿真平台 — 需求规格说明

Status: ready-for-agent
日期：2026-09-30（2026-10-01 grilling 第 4 轮定稿）
来源：grilling 需求访谈（4 轮，已与用户达成共识）
关联：[GLOSSARY.md](../../GLOSSARY.md) · [ADR-0001](../../docs/adr/0001-active-power-curtailment.md)（控制量选有功削减） · [ADR-0002](../../docs/adr/0002-dual-simulation-engine.md)（双仿真引擎）

## 1. 背景与目标

分布式光伏大量接入配电网后，中午大发时段易导致馈线电压越限。本平台让用户自定义配电网模型（节点、拓扑、线路参数、负荷、光伏），用「公平二分法电压调节算法」（其公平系数子模块按论文公式计算）控制光伏有功出力，使全网电压回到安全范围，并通过 OpenDSS / MATLAB 双引擎仿真输出论文级图表。

## 2. 用户与使用场景

- 用户：课题组研究者本人 + 实验室成员；中文界面；不要求看代码即可使用。
- 首要场景：算法验证——改参数 → 跑仿真 → 看电压轨迹/收敛曲线/削减分配 → 导出 PNG + CSV + Excel 写论文。
- 兼顾演示：拓扑电压热力图、控制前后对比、算法展示页（公式与说明）即演示素材。

## 3. 功能需求

### FR-1 网络建模
- 节点：数量不限（性能上限见 NFR-1），编号/名称、相别；负荷按相配置 P、Q（恒功率模型，不建模电压依赖；单位 kW/kvar）；坐标 x/y 可选（缺省按电气距离自动分层布局，供拓扑热力图）。
- 线路：首末端、相别、长度（km）、分相 R/X（Ω/km，相域对角参数，忽略相间互感，两引擎一致建模；或线型库）、载流量（A，用于负载率报告，不参与控制）。
- 光伏：任意节点可配置；相别随 OpenDSS 模型——单相逆变器模型（指定 A/B/C 相，削减作用于该相）或三相模型（单台三相逆变器，额定容量为三相总额定，削减以单值作用于三相、三相同步）；是否参与控制。光伏按单位功率因数建模（ADR-0001）。
- 相制：三相混接网络与纯单相模式均支持。
- 网络级参数：基准电压、频率、平衡节点及其电压、Vmin/Vmax（默认 0.95/1.05 pu）。
- 项目以 JSON 保存/加载（`projects/` 目录），文件含 `schema_version` 字段，加载时校验版本；内置预设：IEEE 33 节点（三相——线路与负荷三相均分复制，复现单相正序潮流值）、小型纯单相示例、IEEE 33 + 高渗透光伏过电压场景（验收与演示用）。
- 拓扑合法性：馈线假设放射状；导入/保存时做环路检测，检出环路即拒绝运行并在界面列出参与环路的节点/线路清单（编辑器允许画，仿真入口拦截）。

### FR-2 出力曲线
- 统一曲线：负荷、光伏各一条 24 点曲线（整点 0–23 时的阶梯值，不做插值），界面表格编辑 + CSV 导入（两列 hour, value，UTF-8）。
- 各节点按自身峰值缩放统一曲线；24h 时序仿真每小时一个断面；快照模式保留（取某小时或手填断面值）。
- 可用出力：光伏可用出力 = 额定容量 × 该断面统一曲线缩放值，是削减量的上限；逆变器效率、温度等 v1 不建模（见 §7 简化假设）。

### FR-3 仿真引擎（ADR-0002）
- OpenDSS 引擎（默认）：opendssdirect.py 内置引擎，无需独立安装；模型翻译为 .dss；三相不平衡潮流；控制闭环内逐轮交互求解。潮流求解设置（算法、收敛容差、最大迭代，见 §5）两引擎取相同配置，保证 NFR-3 可比。
- MATLAB 引擎（可选）：生成完整 .m（网络 + 前推回代潮流 + 算法镜像 + 24h 循环），`matlab -batch` 整体跑完回读结果；MATLAB 路径在设置页配置，自动探测。
- 未安装/未配置 MATLAB 时，除引擎切换外全部功能可用。

### FR-4 电压安全控制（核心，ADR-0001）
- 控制量：光伏有功出力（限幅 [0, 可用出力]），光伏 Q=0。
- 控制目标仅限过电压：全网各节点各相 max(V) ≤ Vmax。Vmin 越限只记录并报告，不作为控制目标、不进验收断言（GLOSSARY「电压安全」据此收窄为单限）。
- 算法：论文给定的电压调节算法「公平二分法」，软件内以**算法展示页**呈现公式与文字说明（论文式 13–16），关键参数开放设定（见 §5）。每个断面的执行流程：
  1. **公平系数**（论文式 13–16，已按论文原文核对修正）：计算各参与控制光伏的公平责任权重 ω_i = (R_i)^α·(C_i)^β / Σ_j (R_j)^α·(C_j)^β：
     - R_i 即时安全责任度（式 13）= |S_vp,i|·P_cur,i / Σ_j |S_vp,j|·P_cur,j。S_vp,i 为光伏 i 对**当前电压越限最严重节点**的有功灵敏度 ∂V_worst/∂P_i；P_cur,i 为光伏 i 当前可削减功率上限（= 当前断面可用出力）。论文中 S_vp 由边缘终端量测估计（式 2–6）；平台已知网络模型，改由潮流摄动精确计算，语义一致。
     - C_i 历史补偿因子（式 15）= exp(−γ·H_i) / Σ_j exp(−γ·H_j)；H_i 历史弃光率（式 14）= Σ_{τ<t} P_cur,i,τ / (Σ_{τ<t} P_ava,i,τ + ε)，P_cur,i,τ 为 τ 断面实际削减功率，ε 为防零小正数，**跨断面累积**。
     - 分区：论文按灵敏度相近性分区（式 7–12）并在分区内归一化；v1 平台以集中计算等价实现，默认**全网单一区域（全局归一化）**，分区为后续扩展（见 §7）。
  2. **总削减量二分**：T = Σ 各光伏可用出力；在 C ∈ [0, T] 上二分搜索总削减量。每轮取区间中值，各光伏削减 = C×w_i（出力 = 可用出力 − 削减），执行潮流检验 max(V)：
     - max(V) > Vmax：削减不足，向多削减方向收敛；
     - max(V) ∈ [Vmax−δ, Vmax]：命中收敛带，停止迭代；
     - max(V) < Vmax−δ：削减过度，向少削减方向收敛，继续。
  3. **收敛与输出**：命中收敛带时取当前削减值；迭代达设定上限仍未命中时，取最后已知可行侧（保守值）并在结果中标注「未收敛」。
  4. **削减分配与钳位**：各光伏削减功率 = C*×w_i；若 C*×w_i > 该光伏可用出力，该光伏削减量 = 其可用出力（全停），结果中标记「已饱和」。
- 24h 模式：潮流与控制逐断面独立（无跨断面爬坡/惯性约束），但 H 跨断面串行累积——必须按小时顺序执行，中途改参数重跑会影响后续时段的公平分配。
- 运行方式：快照单断面收敛；24h 模式逐断面独立收敛并记录全程轨迹。
- 输出：每轮迭代状态（二分区间端点、C、max(V)）、最终 w_i 与各光伏削减功率/出力、收敛标志（命中收敛带 / 达上限未收敛）、越限节点清单、已饱和清单；Jain 公平指标 JFI = (Σ_i r_i)²/(N·Σ_i r_i²)，r_i = 该光伏全程削减电量 / 全程可用电量（论文式 24–26），随结果输出。

### FR-5 通信图
- 默认按电气邻接自动生成光伏代理间通信图及领航者挂接。
- 界面可手动增删边、改权重；与电气拓扑相互独立。断链鲁棒性实验不在 v1 范围。
- 通信图支撑公平责任权重的分布式（领航跟随一致性）实现；平台按论文公式等价地集中计算，两者结果应一致。

### FR-6 对比基线
- 内置两个对照：无控制基线（满发不调节）、集中式基线（不经一致性、直接二分搜全局 k，各光伏等比例削减：出力 = k × 可用出力）。
- 一键运行「基线 vs 公平二分法」并生成对比图。

### FR-7 结果展示与导出
- 图：24h 电压轨迹（分相可选）、迭代收敛曲线、削减分配柱状图、拓扑电压热力图（节点按电压着色）。图表用 matplotlib 输出，PNG 300 DPI，中文标签显式配置字体（不得出现方框乱码）。
- 导出：图表 PNG、数据 CSV、Excel 工作簿（每数据集一表）。
- 持久化：每次运行落盘 `results/<run-id>/`（run-id = 时间戳 + 项目名），固定四个数据集：① 场景摘要 ② 24h 电压轨迹 ③ 削减分配 ④ 迭代历史；CSV 全量，Excel 四表对应。
- 历史运行：UI 提供运行列表，可回看任意历史 run 的结果（只读）。

### FR-8 界面与运行方式
- NiceGUI 中文 Web 界面（本地浏览器访问）：① 网络编辑器 ② 拓扑/热力图 ③ 仿真与结果 ④ 算法展示页（公平二分法公式与说明 + 关键参数设定入口）⑤ 设置。
- CLI 无界面运行：`python -m pvvr run project.json [--mode snapshot|24h] [--t N] [--engine opendss|matlab] [--out DIR]`，供批处理与测试；参数语义与 Web 按钮一一对应；`python -m pvvr ui` 启动 Web 界面。

### FR-9 输入校验与异常处理
- 输入校验：JSON 结构校验 + 领域校验（节点编号唯一、线路端点存在、相别合法、光伏容量非负、曲线 24 点、参数范围）；报错信息中文，定位到字段/条目。
- 运行期异常分类报告：潮流不收敛、二分不可行/未收敛、MATLAB 路径无效或版本不符——各给明确结论与建议，不静默失败、不崩溃退出。

## 4. 非功能需求

- NFR-1 规模与性能：≤300 节点馈线，单断面潮流毫秒级；24h+控制闭环在秒级完成（OpenDSS 模式）。
- NFR-2 环境：Python 3.8 兼容（同时兼容 3.12）；OpenDSS 引擎随 pip 依赖内置；MATLAB R2024b 可选。
- NFR-3 引擎一致性：同一模型同一算法，OpenDSS 与 MATLAB 引擎的电压结果偏差 ≤0.001 pu。
- NFR-4 算法模块化：公平系数计算 + 二分控制集中在单文件（`engine/control.py` 及其 MATLAB 镜像），替换公式不影响其余部分。
- NFR-5 并发使用：v1 为单活跃项目工作区，面向单用户串行使用；检测到项目文件被外部改动时提示重载；多人并发编辑不承诺，本 limitation 在文档中明示。
- NFR-6 可复现性：无随机源；同一项目同一参数多次运行，数值结果与导出文件完全一致。
- NFR-7 部署：源码方式运行（不做安装器/打包）；requirements.txt 固定兼容 Python 3.8 的依赖版本；仓库 README 提供快速开始（安装依赖 → 启动 Web/CLI）。

## 5. 关键参数（算法展示页 + 设置页 + 项目 JSON 均可设定）

| 参数 | 含义 | 默认值 |
| ---- | ---- | ---- |
| Vmin / Vmax | 电压区间（Vmax 为控制目标，Vmin 仅记录） | 0.95 / 1.05 pu |
| δ | 二分收敛带精度，max(V) ∈ [Vmax−δ, Vmax] 即停 | 0.0005 pu |
| 迭代上限 | 二分最大轮数，耗尽取保守可行侧并标注 | 60 |
| α、β | 公平责任权重中即时责任度 R 与历史补偿因子 C 的分配指数 | 论文正文未给出取值（4.3.4 节仅灵敏度分析），v1 占位 1 / 1 |
| γ | 历史补偿因子调节参数 | 论文正文未给出取值，v1 占位 1 |
| 潮流收敛容差 | OpenDSS（Newton）与 MATLAB（前推回代）共用的电压收敛判据 | 1e-4 pu |
| 潮流最大迭代 | 单次潮流求解最大迭代数，超出判不收敛并报错 | 100 |

## 6. 测试需求

- ET-1 基态回归：IEEE 33 预设（Baran & Wu 原始数据、三相均分复制）重跑，最低电压断言 0.913 pu（节点 18）容差 0.5%。
- ET-2 双引擎一致性：固定小模型同算法，OpenDSS 与 MATLAB 的 max 电压偏差 ≤1e-3 pu。
- ET-3 闭环行为测试：构造小场景，断言二分命中收敛带或达上限取保守侧、削减分配 = C*×w_i、越界钳位全停并标记。

## 7. 简化假设（v1 有意不做）

- 逆变器效率、温度、限功率等不建模：可用出力 = 额定 × 曲线值。
- 24h 断面间无爬坡/惯性约束（电力上逐断面独立）；仅公平状态 H 跨断面累积。
- 低电压跌落不控制、仅记录报告（ADR-0001 语境）。
- 节点坐标可缺省（自动分层布局），非必填。
- α/β/γ 等算法参数值以论文为准，软件仅提供占位默认值与设定入口。
- 论文分区机制（式 1–12）v1 不实现：平台默认全网单一区域、公平责任权重全局归一化；量测灵敏度估计（式 6）由模型潮流摄动计算替代。
- 二分法中各光伏按 ω_i 同步削减（式 25）；单光伏 ω_i·C* 超出其可用出力时的钳位全停为平台工程保护（论文未述），结果中标记「已饱和」。

## 8. 验收标准

1. IEEE 33 节点基态潮流最低电压 ≈0.913 pu（节点 18），与文献偏差 <0.5%。
2. 高渗透光伏过电压场景下，控制收敛后全网 max(V) ≤ Vmax（只断言上侧；Vmin 越限如实记录）。
3. 24h 仿真输出全程电压轨迹与控制动作，可导出 PNG/CSV/Excel，落盘 `results/<run-id>/` 四数据集。
4. 同一模型同一算法，两引擎电压结果偏差 ≤0.001 pu。
5. 无 MATLAB 环境：OpenDSS 全流程（建模→仿真→控制→导出）可用。
6. 含环路的项目在运行入口被拒绝，并列出参与环路的节点/线路。
7. 同一项目同一算法，CLI 与 Web 结果一致。
8. ET-1 / ET-2 / ET-3 通过。

## 9. 论文核对结果（2026-10-01 对照论文 PDF，T-1 关闭）

- Q-1 公平责任权重更新时机 — **已确认**：每时段（断面）开始计算一次 ω_i，二分过程中固定；H 取截至 t−1 断面的历史（论文式 14 明确「截至时段 t-1」）。
- Q-2 公平状态运行边界 — **已确认**：H 自运行起点累积，每次运行重置（论文按仿真窗运行，无跨运行持久化）。
- δ = 0.0005 pu 收敛标准、Vmax = 1.05 pu（式 18）与 §5 默认一致。
- α/β/γ 具体取值论文正文未给（4.3.4 仅灵敏度分析），维持占位 1，论文定稿后在此登记。
