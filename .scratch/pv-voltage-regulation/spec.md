# 分布式光伏电压调节仿真平台 — 需求规格说明

Status: needs-triage

关联：[GLOSSARY.md](../../GLOSSARY.md) · [ADR-0001](../../docs/adr/0001-active-power-curtailment.md)（控制量选有功削减） · [ADR-0002](../../docs/adr/0002-dual-simulation-engine.md)（双仿真引擎）

## 1. 背景与目标

分布式光伏大量接入配电网后，中午大发时段易导致馈线电压越限。本平台让用户自定义配电网模型（节点、拓扑、线路参数、负荷、光伏），用「领航跟随一致性（内层）+ 二分法（外层）」控制光伏有功出力，使全网电压回到安全范围，并通过 OpenDSS / MATLAB 双引擎仿真输出论文级图表。

## 2. 用户与使用场景

- 用户：课题组研究者本人 + 实验室成员；中文界面；不要求看代码即可使用。
- 首要场景：算法验证——改参数 → 跑仿真 → 看电压轨迹/收敛曲线/削减分配 → 导出 PNG + CSV + Excel 写论文。
- 兼顾演示：拓扑电压热力图、控制前后对比即演示素材。

## 3. 功能需求

### FR-1 网络建模
- 节点：数量不限（性能上限见 NFR-1），编号/名称、相别；负荷按相配置 P、Q。
- 线路：首末端、相别、长度、分相 R/X（或线型库）、载流量。
- 光伏：任意节点可配置；单相（指定 A/B/C 相）或三相；额定容量；是否参与控制。
- 相制：三相混接网络与纯单相模式均支持（ADR-0001 语境下光伏均按单位功率因数建模）。
- 网络级参数：基准电压、频率、平衡节点及其电压、Vmin/Vmax（默认 0.95/1.05 pu）。
- 项目以 JSON 保存/加载（`projects/` 目录）；内置预设：IEEE 33 节点（三相）、小型纯单相示例。

### FR-2 出力曲线
- 统一曲线：负荷、光伏各一条 24 点曲线，界面表格编辑 + CSV 导入。
- 各节点按自身峰值缩放统一曲线；24h 时序仿真每小时一个断面；快照模式保留（取某小时或手填断面值）。

### FR-3 仿真引擎（ADR-0002）
- OpenDSS 引擎（默认）：opendssdirect.py 内置引擎，无需独立安装；模型翻译为 .dss；三相不平衡潮流；控制闭环内逐轮交互求解。
- MATLAB 引擎（可选）：生成完整 .m（网络 + 前推回代潮流 + 算法镜像 + 24h 循环），`matlab -batch` 整体跑完回读结果；MATLAB 路径在设置页配置，自动探测。
- 未安装/未配置 MATLAB 时，除引擎切换外全部功能可用。

### FR-4 电压安全控制（核心，ADR-0001）
- 控制量：光伏有功出力（限幅 [0, 可用出力]），光伏 Q=0。
- 外层：二分法搜索全局削减系数 k∈[0,1]，使出力 = k × 可用出力时全网电压恰好安全。
- 内层：领航跟随一致性——跟随者按通信图迭代交换信息，由「公平性标准」给出各光伏的削减系数（**公式待用户提供论文 PDF，框架先以等比例削减占位**）。
- 运行方式：快照单断面收敛；24h 模式逐断面独立收敛并记录全程轨迹。
- 输出：每轮迭代的电压、各代理削减系数/出力、收敛判据。

### FR-5 通信图
- 默认按电气邻接自动生成光伏代理间通信图及领航者挂接。
- 界面可手动增删边、改权重；与电气拓扑相互独立。断链鲁棒性实验不在 v1 范围。

### FR-6 对比基线
- 内置两个对照：无控制基线（满发不调节）、集中式基线（不经一致性、直接二分搜全局 k）。
- 一键运行「基线 vs 领航跟随二分法」并生成对比图。

### FR-7 结果展示与导出
- 图：24h 电压轨迹（分相可选）、迭代收敛曲线、削减分配柱状图、拓扑电压热力图（节点按电压着色）。
- 导出：图表 PNG、数据 CSV、Excel 工作簿（每数据集一表）。

### FR-8 界面与运行方式
- NiceGUI 中文 Web 界面（本地浏览器访问）：① 网络编辑器 ② 拓扑/热力图 ③ 仿真与结果 ④ 设置。
- CLI 无界面运行：`python -m pvvr run project.json`，供批处理与测试。

## 4. 非功能需求

- NFR-1 规模与性能：≤300 节点馈线，单断面潮流毫秒级；24h+控制闭环在秒级完成（OpenDSS 模式）。
- NFR-2 环境：Python 3.8 兼容（同时兼容 3.12）；OpenDSS 引擎随 pip 依赖内置；MATLAB R2024b 可选。
- NFR-3 引擎一致性：同一模型同一算法，OpenDSS 与 MATLAB 引擎的电压结果偏差 ≤0.001 pu。
- NFR-4 算法模块化：领航跟随一致性 + 公平性分配集中在单文件（`engine/control.py` 及其 MATLAB 镜像），替换公式不影响其余部分。

## 5. 待定项

- T-1 公平性削减系数公式：用户将提供论文 PDF/图片；到位前以等比例削减占位（占位实现不影响验收以外的开发推进）。

## 6. 验收标准

1. IEEE 33 节点基态潮流最低电压 ≈0.913 pu（节点 18），与文献偏差 <0.5%。
2. 高渗透光伏过电压场景下，控制收敛后全网电压 ∈ [Vmin, Vmax]。
3. 24h 仿真输出全程电压轨迹与控制动作，可导出 PNG/CSV/Excel。
4. 同一模型同一算法，两引擎电压结果偏差 ≤0.001 pu。
5. 无 MATLAB 环境：OpenDSS 全流程（建模→仿真→控制→导出）可用。
