# 控制量选用光伏有功削减，光伏按单位功率因数建模

电压调节文献多以光伏逆变器无功出力为控制量，但用户的论文方法通过削减光伏有功出力保证电压安全。因此 v1 的唯一控制量是光伏有功（逆变器限幅 [0, 可用出力]），光伏按单位功率因数（Q=0）建模，二分法搜索的全局削减系数直接作用于有功。数据结构预留无功能力字段，但控制器与生成的仿真模型均不使用。

## Considered Options

- 仅无功 Q 调节（主流做法）——与用户论文方法不符，弃
- 无功 + 有功混合——v1 复杂度显著上升，留作后续扩展

## Consequences

对「光伏大发导致电压抬升」场景有效；对重负荷导致电压跌落场景无调节能力（届时电压安全判据会如实报告越限）。将来若引入无功调节，需同时改控制算法与 MATLAB 镜像。
